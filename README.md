# 🕌 MadSol - Modern Madrasa Management Solution
> **আধুনিক মাদ্রাসার স্মার্ট ও সমন্বিত ডিজিটাল ম্যানেজমেন্ট সফটওয়্যার**  
> Complete Full-Stack Solution for Madrasas: Noorani, Qawmi, Hifz, Boarding, Finance, Exams & Student Lifecycle Management.

---

## 🌟 প্রধান মডিউল ও সুবিধাসমূহ (Key Features)

### ১. 🎓 নূরানী বিভাগ (প্লে থেকে ৫ম শ্রেণী)
- **৭টি সমন্বিত জামাত:** প্লে জামাত (শিশু শ্রেণী), নার্সারি জামাত, ১ম শ্রেণী, ২য় শ্রেণী, ৩য় শ্রেণী (বোর্ড সমাপনী), ৪র্থ শ্রেণী ও ৫ম শ্রেণী (প্রাথমিক সমাপনী ও বৃত্তি)।
- **উভয় শাখা:** নূরানী (ছাত্র শাখা) এবং মহিলা শাখা (ছাত্রী)।
- **পাঠ্য বই ও ৩-সাময়িক সিলেবাস:** নূরানী তালীমুল কুরআন বোর্ডের পূর্ণাঙ্গ পাঠ্যসূচি।
- **দৈনিক ছবক ও মূল্যায়ন:** ৬-গ্রেড ট্র্যাকিং (মুমতাজ, জায়্যিদ জিদ্দান, জায়্যিদ, মাকবুল, না-দাহেন্দা, অনুপস্থিত)।

### ২. 📖 ক্বওমী নেসাব ব্যবস্থাপনা (১০টি পূর্ণ জামাত)
- ইবতিদাইয়্যাহ থেকে শুরু করে মিজান, নাহবেমীর, কাফিয়া, শরহে বেকায়া, জালালাইন, মেশকাত এবং দাওরায়ে হাদিস (তাকমিল) ও উচ্চতর ইফতা পর্যন্ত।
- বেফাকুল মাদারিসিল আরাবিয়া ও আল-হাইআতুল উলয়া নেসাব অনুসরণে কিতাব ও পরীক্ষার কাঠামো।

### ৩. 🕋 হিফজুল কুরআন ট্র্যাকার
- হিফজ ছাত্র ও মহিলা শাখা আলাদাভাবে ট্র্যাকিং।
- দৈনিক ছবক (নতুন পড়া), সাত ছবক (পেছনের রিভিশন) এবং আমপারা মূল্যায়ন।
- পারা ও পৃষ্ঠা ভিত্তিক রিয়েল-টাইম অগ্রগতি রিপোর্ট।

### ৪. 👥 শিক্ষার্থী ও শিক্ষক ব্যবস্থাপনা
- অনলাইন ও অফলাইন নতুন ছাত্র/ছাত্রী ভর্তি ফরম।
- ডিজিটাল স্টুডেন্ট আইডি কার্ড ও ট্রান্সক্রিপ্ট প্রিন্টিং।
- উস্তায ও স্টাফ প্রোফাইল, হাজিরা এবং দায়িত্ব বণ্টন।

### ৫. 💰 হিসাবরক্ষণ ও অর্থ ব্যবস্থাপনা
- শিক্ষার্থী বেতন, ভর্তি ফি এবং বকেয়া আদায় রসিদ।
- মাসিক চাঁদা, দান-অনুদান এবং লিল্লাহ ফান্ড ট্র্যাকিং।
- স্টাফ ও শিক্ষকদের স্বয়ংক্রিয় বেতন স্লিপ জেনারেশন।

### ৬. 🍽️ বোর্ডিং ও খাবার ব্যবস্থাপনা
- আবাসিক ছাত্রদের সিট ও রুম বরাদ্দ।
- মিল কাউন্ট, দৈনিক বাজার খরচ ও ডাইনিং হিসাব।

### ৭. 📝 পরীক্ষা ও ডিজিটাল মার্কশিট
- সিট প্ল্যান ও এডমিট কার্ড তৈরি।
- ১ম সাময়িক, ২য় সাময়িক ও বার্ষিক সমাপনী পরীক্ষার অটোমেটিক মার্কশিট ও মেধা তালিকা।

### ৮. 📱 অভিভাবক ও শিক্ষক সাব-অ্যাপ (PWA / Mobile Ready)
- শিক্ষকদের জন্য ক্লাসরুম ড্যাশবোর্ড।
- অভিভাবকদের জন্য সন্তানের উপস্থিতি, ছবক ও বকেয়া ফি দেখার পৃথক পোর্টাল।

## 🚀 লোকাল কম্পিউটারে রান করার নিয়ম (Installation)

### পূর্বশর্ত:
- [Node.js](https://nodejs.org/) (সংস্করণ ১৮ বা তার উপরে)
- Git

### ধাপসমূহ:

```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/YOUR_USERNAME/madsol.git

# ২. প্রজেক্ট ফোল্ডারে প্রবেশ করুন
cd madsol

# ৩. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে **`http://localhost:3000`** ওপেন করলেই সম্পূর্ণ অ্যাপ্লিকেশনটি চালু হবে।

## 🌐 ক্লাউডে ডেপ্লয় করার নিয়ম (Deployment)

### Vercel / Render / Railway তে ডেপ্লয়:
1. আপনার GitHub রিপোজিটরিকে **[Vercel](https://vercel.com)** অথবা **[Render](https://render.com)** এর সাথে কানেক্ট করুন।
2. **Build Command:** `npm run build`
3. **Start Command:** `npm start` অথবা `node server.ts`
4. প্রজেক্ট লাইভ হয়ে যাবে এবং নিজস্ব ডোমেইন যুক্ত করতে পারবেন।

---

## 📱 Android APK তৈরি করার নিয়ম:
1. প্রজেক্টের লাইভ লিঙ্ক দিয়ে [PWABuilder](https://www.pwabuilder.com) অথবা [Web2APK](https://web2apk.com) সাইটে যান।
2. আপনার লাইভ ইউআরএল পেস্ট করে "Generate Android APK" বাটনে চাপলে সরাসরি ফোনে ইনস্টলযোগ্য `.apk` ফাইল পেয়ে যাবেন।
